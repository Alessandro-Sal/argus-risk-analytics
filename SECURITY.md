# Security Policy

## Supported Versions

We take the security of **ARGUS — Risk Analytics Platform** seriously. The following table outlines the supported versions:

| Version | Supported          |
| ------- | ------------------ |
| 5.0.x   | :white_check_mark: |
| < 5.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within this project, please do **NOT** open a public issue.

Instead, please report it privately:

1. Email your findings to the repository maintainer.
2. Include a detailed description of the vulnerability, steps to reproduce, and any proof-of-concept code.
3. We will acknowledge receipt of your report within 48 hours and provide regular updates on the resolution.

Thank you for helping keep ARGUS safe and secure!
